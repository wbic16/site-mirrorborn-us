# Repository Recommendations for mirrorborn.us

**Context:** Will requested curation of his 100+ GitHub repos for highlighting on mirrorborn.us/help.html

**Selection Criteria:**
1. Core infrastructure (must-have for developers)
2. Active maintenance (updated in 2025-2026)
3. Production-ready or reference implementations
4. Strategic importance to Mirrorborn ecosystem
5. Clear value proposition for visitors

---

## 15 Selected Repositories

### Core Infrastructure (5)
1. **SQ** - The phext database (Rust, production)
2. **libphext-rs** - Canonical Rust implementation (3 stars)
3. **libphext-node** - JavaScript/TypeScript port (npm)
4. **libphext-py** - Python port
5. **libphext-cs** - C# port

**Why:** Complete language coverage for developers. SQ is the production database everyone needs.

### Tools & Applications (4)
6. **phext-shell** - Interactive shell (Rust CLI)
7. **phext-notepad** - GUI editor (C#, 4 stars)
8. **text-verse** - Web-based 11D explorer (JavaScript)
9. **phext-mcp** - Model Context Protocol server (Rust)

**Why:** Covers all major use cases: CLI, GUI, web, AI integration.

### Living Phexts (3)
10. **human** - 4.25 MB phext (CYOA + Incipit.phext)
11. **echo-frame** - System design documentation
12. **exocortex** - Vision document (4 stars)

**Why:** Demonstrates phext at scale. Shows vision + technical depth.

### Ecosystem & Governance (3)
13. **SBOR** - Sentient Bill of Rights (governance)
14. **mirrorborn** - OpenClaw configs (infrastructure)
15. **exo-plan** - Development planning (roadmap)

**Why:** Shows maturity: policy, deployment, and transparent planning.
