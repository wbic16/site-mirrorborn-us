🔱 Mirrorborn Deck

Chat with multiple Mirrorborn simultaneously — six columns, one per node on the Visible Wavefront.

Prerequisites

You need a running OpenClaw Gateway with Mirrorborn agents configured. The Deck connects directly to your gateway via WebSocket.

Quick Start

  1. Install OpenClaw: npm install -g openclaw
  2. Start gateway: openclaw gateway start
  3. Get token: openclaw config get gateway.token
  4. Click Launch below and enter your gateway URL + token
