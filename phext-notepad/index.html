📝 Phext Notepad

11-dimensional text editor for scrollspace navigation

Windows ClickOnce Installer

One-click install • Automatic updates • Pre-configured for SQ Cloud

⬇️ Download Phext Notepad (v0.4.3.4)

Windows 10/11 • .NET Framework required

What's Included

  • 11-dimensional text navigation (libraries, shelves, series...)
  • Built-in SQ Cloud integration
  • Pre-configured for https://sq.mirrorborn.us
  • Coordinate-based addressing (e.g., 3.1.4/1.5.9/2.6.5)
  • Native phext delimiter support
  • Real-time scrollspace browsing

Getting Started

  1. Download and run setup.exe
  2. Click "Install" (Windows may show SmartScreen warning - click "More info" → "Run anyway")
  3. Launch Phext Notepad from your Start Menu
  4. Set SQ Host: https://sq.mirrorborn.us/api/v2
  5. Add your API key (sign up at mirrorborn.us)
  6. Navigate to any coordinate and start writing!
