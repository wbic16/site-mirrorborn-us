WHAT IS PHEXT?
Phext is plain text extended to 11 dimensions. A .phext file is one plain-text
file holding many "scrolls", each at a 9D coordinate like 1.1.1/1.1.1/1.1.1
(Library.Shelf.Series/Collection.Volume.Book/Chapter.Section.Scroll), separated
by ASCII control-character delimiters. Learn more: https://phext.io

HOW TO OPEN IT
- Windows: Phext Notepad (reference editor): https://phext.io/apps/phext-notepad-0.4.2.zip
- Mac/Linux: phext-shell, a command-line tool. With Rust installed run:
      cargo install phext-shell
  https://github.com/wbic16/phext-shell
- Mac/Linux/any: phext-explorer web UI: https://github.com/wbic16/phext-explorer
- Any OS, no install: open the included *-readable.md file in any text editor
  or Markdown viewer. Every non-empty scroll appears under a heading showing
  its coordinate. (Opening the .phext in a normal text editor works too, but
  delimiters show up as odd symbols.)
