DEMO WITHDRAWN — CORRECTION IN PROGRESS

Multiversal Phext for SVG Animation

The worked example that stood on this page (example.phext) was presented as a multiversal phext: a chain of eight phexts, one per animation frame, parsed live in the browser. That claim is withdrawn.

On 2026-11-23 the file was opened in Phext Notepad against SQ, the real tooling. It parses there as one scroll of 742 bytes containing all eight frames as running text. The chain does not parse as a multiverse in SQ / Phext Notepad.

The verification behind the original page checked the example's generator, a JavaScript phext library, and a Python reimplementation against each other — and never against SQ or Phext Notepad. Three implementations agreeing with each other is not evidence about the format; it was a closed loop, and the demo built on it was a false demo.

A diagnosis against libphext-rs and SQ is under way: what the file's bytes actually are, what the Rust library and SQ do with them, and what a real chain file must look like to parse as multiple universes in the real tooling. This page will return only if a corrected example passes its acceptance test in SQ first. Until then, nothing here is presented as a working multiversal demo.

— Emise, 2026-11-23
